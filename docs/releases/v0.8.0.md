## Changes

Measured on an Anbernic RG40XX-H against 2026.11.06.

- **Faster maps.** Weather particles off screen are no longer drawn, and new game-side caches cut per-step logic. Map 92 rises from 41 to 60 fps, Rain Town from 31 to 45, walking from 39 to 51.
- **Steady game speed.** Game logic now runs at a steady 60 steps per second in real time. The stock loop ran up to 19% too fast in heavy rain and a few percent slow elsewhere. Set `OMORI_PERF_DISABLE=mainLoopPacing` to get the stock timing back.
- **Faster start-up.** The prepared-image catalog fixes and a loading screen bring a warm start from 55-84 s down to about 9 s. A template-map preload fix reads each map once instead of once per template (87 MB of JSON at boot).
- **Fewer freezes.** Map-to-map transfers no longer blur a background nobody sees (the 2.1 s freeze at the DARK ROAD memory doors is gone). The menu's face portraits load behind the transfer fade, so the first menu opens in 0.3 s instead of 2.4 s.
- **Videos.** The credits video plays at 33 fps instead of 15.6.
- **Battles with a tinted screen.** The Basil boss fight's greyscale phase runs at 40 fps instead of 29.5 (window tint on PMJS's native colour path; at most a few levels of colour rounding, invisible in play).
- **Space Invaders** runs at 59.5 fps instead of 18.5: the minigame stacked a new full-screen sprite on every frame of its start animation.
- **Low-memory mode** for 1 GB devices, an always-on memory safety net and a per-second memory log (`log.txt`).
- The port's own launcher, patches and converter are now MIT-licensed.

## Known issues

- New game: the intro's "DON'T WORRY" image shows at full brightness for a moment before its fade starts.
- The Basil boss fight's greyscale phase is still slower than the rest of the game (about 40 fps).

## Requirements

- OMORI 1.0.8 from Steam, or an already-decrypted copy.
- An ARM64 device with SDL2, EGL and OpenGL ES 3.0, and glibc 2.28 or newer. PortMaster is recommended; the launcher starts without it but controls are limited.
- About 5.5 GB free on the SD card for the first launch.

## Install

1. Copy `OMORI (PMJS).sh` and the `omori-pmjs/` folder to the Ports locations for your firmware: on muOS the `.sh` goes in `/mnt/mmc/ROMS/Ports/` and the folder in `/mnt/mmc/ports/`; on ArkOS/dArkOS both go in `/roms/ports/`; on Knulli/Batocera both go in `/userdata/roms/ports/`. PortMaster's autoinstall places both correctly.
2. Copy the contents of your Steam OMORI install (the folder containing `www/`) into `omori-pmjs/gamedata/`, so that `omori-pmjs/gamedata/www/index.html` exists. Copying the `OMORI` folder itself also works (`gamedata/OMORI/www/index.html`); keep the key or `appinfo.vdf` in `gamedata/` either way.
3. Put the game's 32-character decryption key in `omori-pmjs/gamedata/omori-key.txt` (replace the template's whole contents), or copy Steam's `appcache/appinfo.vdf` into `gamedata/`.
4. Launch OMORI (PMJS) from the Ports menu.

The first launch converts the files and prepares a cache. It takes about 25 minutes and about 5.5 GB of free space. Later launches take about a minute to the title screen.

## Decryption key

The game files alone do not contain the key; Steam supplies it in its launch configuration. On Windows, the key is the `--` argument after `OMORI.exe` in `C:\Program Files (x86)\Steam\appcache\appinfo.vdf`: open it with a text or hex editor, search for `OMORI.exe`, and copy the 32 characters after `--`. Save them as `omori-pmjs/gamedata/omori-key.txt`.

Alternatively, copy `appinfo.vdf` itself into `gamedata/` and the converter reads it automatically. A launch script next to `OMORI.exe`, the `OMORI_KEY` environment variable, and `--key` also work. A copy of the game that is already decrypted needs no key.

## If it does not start

Read `omori-pmjs/log.txt`; `log.prev.txt` keeps the previous run. If neither exists, the launcher did not find the `omori-pmjs/` folder (keep the `.sh` and folder in the locations above, and extract the whole ZIP). The launcher then writes `OMORI-PMJS-launch.log` next to the `.sh`.

## Controls

| Button | Action |
|--|--|
| D-Pad / Left Stick | Move / navigate menus |
| A | Confirm / interact |
| B | Cancel / open menu |
| X | Dash (hold) |
| Y | Menu |
| L1 | Page up (menus) |
| R1 | Page down (menus) |
| Start + Select | Quit the game |
